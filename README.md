# 日常账本 · 安卓测试版更新

此仓库只分发公开安装文件、版本清单与校验信息，不保存用户账目或签名私钥。

## 从 0.3.0 开始测试

1. 先导出个人账本备份，然后下载并覆盖安装 [0.4.0 引导升级包](updates/releases/daily-ledger-v0.4.0.apk)。保留原应用，不要先卸载。
2. 打开「账本设置 → 软件更新 → 检查更新」，在 App 中下载并升级到 0.4.1。
3. 首次可能需要允许「日常账本」安装更新，再按系统提示确认。

[直接下载最新测试版 0.4.1](updates/releases/daily-ledger-v0.4.1.apk)

0.4.1 是更新链路验证版，功能与 0.4.0 相同。两者均与 0.3.0 使用同一应用标识和签名。真实手机中的安装、升级与账目保留仍需要实际验证，不把构建与签名校验等同于真机验证。

## 数据与联网

日常记账离线使用。仅在用户手动检查或下载更新时请求公开版本信息和安装文件，不向更新服务上传账目。不含广告、登录或统计功能。

新版本申请联网和请求安装更新权限。系统安全提醒和安装确认由手机控制。不同网络对 GitHub 下载域名的可达性可能不同，不保证所有网络免 VPN 访问。
